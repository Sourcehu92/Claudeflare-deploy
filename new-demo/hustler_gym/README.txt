HUSTLER GYM — responsive demo website

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Keep the css, js and assets folders beside index.html.

PROJECT FILES
- index.html: page structure and content
- css/style.css: responsive design and animations
- js/script.js: modal, form demo and lightweight reveal effects
- assets/: local photos and brand artwork

NOTES
- All website photography used by the page is bundled locally in assets/.
- Login/signup forms are front-end demos and are not connected to a database.
- Google Fonts may load from the internet; system fallbacks are provided.
- Mobile layout intentionally uses a clean header without a fixed bottom navigation bar.
