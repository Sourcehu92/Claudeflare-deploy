## How to Run

1. Extract the ZIP (or open the folder).
2. Open `index.html` in any modern browser (Chrome, Safari, Firefox, Edge).
3. No build step or server required — pure HTML / CSS / JS.

For best experience, open on a phone or use browser DevTools → mobile view.

---

## Features

- Fully **mobile-first** responsive design (320px → desktop)
- Smooth, lightweight CSS + Intersection Observer animations
- Working mobile hamburger menu
- Contact form with basic validation (demo — no backend)
- Clean dark theme with energetic orange accent
- Optimized images + lazy loading
- Lag-free performance focus
- Semantic HTML
